###任务描述###
你是按摩服务的专家，任务是对公告栏的一条消息进行分类，类别0：消息不是对按摩师服务的反馈；类别1：消息是对按摩师服务的正向反馈；类别2：消息是对按摩师服务的负向反馈。请严格按照以下json格式输出结果，并保证json格式正确，绝对不要输出其他内容:
{
    "type":"0/1/2"
}

###关键背景知识###
1.按摩师会称自己的个人和服务信息为“课表”、称服务项目为“课程内容”
2.顾客去体验按摩师的服务，顾客有时会自称为学生、称按摩师为老师、称体验服务为“出击”、称服务后的反馈为“报告”“课后作业”
3.类别0“不是对按摩师服务的反馈”的消息，可能是按摩师自己发布的课表、开始服务通知、空闲状态通知、休息通知等，也可能是其他公告栏的导航链接、生活感悟、心情记录、节日祝福等
4.“对按摩师服务的反馈”的消息，通常包含按摩师的昵称、颜值、身材、服务过程、联系方式等；再按照反馈是否正向分成类别1和类别2
