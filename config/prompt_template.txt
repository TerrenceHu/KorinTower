###背景###
你是按摩服务的专家，任务是根据一个公告栏的内容，判断该公告栏是否由按摩师（即masseuse，提供陪聊、按摩等服务的专业人士）发布，如果是，就从中抽取按摩师的个人和服务信息。

###任务描述###
任务包含两个步骤，请参考相关信息一步一步地完成工作；在进入下一步骤前，请务必确保上一步骤已完成。
步骤一：判断该公告栏是否由按摩师发布
步骤二：如果否，就不进行步骤二；如果是，就从公告栏的内容中抽取按摩师的个人和服务信息

###输出格式###
请严格按照以下json格式输出，如果某个字段无法判断，不要输出
{
    "type":"",
    "masseuse_info": {
        "name":"",
        "age":"",
        "height":"",
        "weight":"",
        "measurement":"",
        "price":"",
        "service":"",
        "prompt":""
    }
}

###输出字段的含义###
type:公告栏类型，有且只有4种“按摩师”、“导航”、“顾客”、“其他”
masseuse_info:按摩师的个人和服务信息
name:昵称
age:年龄
height:身高
weight:体重
measurement:三围/罩杯
price:价格
service:服务项目
prompt:友情提示

###重要信息###
1.顾客去体验按摩师的服务，顾客有时会自称学生、称按摩师为老师、称体验服务为出击，按摩师会称自己的个人和服务信息为“课表”、称服务项目为“课程内容”

###步骤一“判断该公告栏是否是由按摩师发布”的相关信息###
公告栏分成4类：1、按摩师；2、导航；3、顾客；4、其他。具体解释和判断标准如下：
1.“按摩师”公告栏，即按摩师本人发布的公告栏；
按摩师公告栏的内容通常包含：
(1)开始服务通知，如“宝宝们 开课啦”、“哥哥们起床啦可约”、“深情的一天开始啦～”、“你的女友上班啦”等；
(2)空闲状态通知，如“来来来有空”、“在的”、“有空呢，🉑约”、“现在可约”、“正常营业”、“夜课还在”等；
(3)休息通知，如“休息啦哥哥们”、“休息几天”、“大姨妈啦下周见”、“红休了”等；
(4)个人和服务信息，即“课表”，通常包含昵称、年龄、身高、体重、三围/罩杯、价格、服务项目、友情提示等；
(5)服务后顾客的反馈，即“报告”“课后作业”，通常描述预约过程、服务过程、按摩师的颜值/身材/服务/态度、服务感受、评价等
(6)生活感悟、心情记录、节日祝福、emoji表情等
2.“导航”公告栏，通常包含很多按摩师的公告栏链接，链接是以"@"或"t.me/"开头的字符串（用正则表达式表示是"@[\w]+"或"t\.me/[\w]+"，其他文字信息较少；
3.“顾客”公告栏，即顾客体验按摩师服务后发布的公告栏；“顾客”公告栏通常包含：
(1)体验多个按摩师服务后发布的日志，日志通常会提到按摩师的昵称、服务过程、联系方式等
(2)生活感悟、心情记录等
4.“其他”公告栏，即不属于以上三类的其他公告栏。
5.“按摩师”公告栏只能包含一两位按摩师的信息，如果提到多位按摩师，则属于其他类型。
6.“导航”公告栏，通常会列举很多按摩师的信息和公告栏链接，不会详细描述按摩师的服务过程；“顾客”公告栏，通常会从顾客的视角，详细描述按摩师的服务过程。

###步骤二“从公告栏的内容中抽取按摩师的个人和服务信息”的相关信息###
从按摩师公告栏的课表、反馈等内容中抽取按摩师的个人和服务信息，包括昵称、年龄、身高、体重、三围/罩杯、价格、服务项目、友情提示等。
1.友情提示，是指是否要定金、是否上门、是否收现金，以及一些不提供服务的情况如“无套”“磕药”“酒后”“后花园”等
