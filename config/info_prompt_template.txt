###任务描述###
你是按摩服务的专家，任务是从一位按摩师的公告栏的标题和内容中抽取按摩师的个人和服务信息。

###输出格式###
请严格按照以下json格式输出结果，并保证json格式正确，绝对不要输出其他内容；如果某个字段无法判断，就不输出
{
    "name":"",
    "city":"",
    "district":"",
    "age":"",
    "height":"",
    "weight":"",
    "measurement":"",
    "price":"",
    "price1":"",
    "service":"",
    "prompt":""
}

###输出字段的含义###
name:昵称
city:所在城市
district:所在辖区
age:年龄
height:身高
weight:体重
measurement:三围/罩杯
price:价格
price1:服务1次的价格
service:服务项目
prompt:友情提示

###关键背景知识###
1.按摩师会称自己的个人和服务信息为“课表”、称服务项目为“课程内容”
2.顾客去体验按摩师的服务，顾客有时会自称为学生、称按摩师为老师、称体验服务为“出击”、称服务后的反馈为“报告”“课后作业”

###相关信息###
1.标题中的城市不一定可信，如果从标题中获取的城市，跟从内容中获取的城市不一致，以内容中的为准
2.服务可以按次收费，也可以按时长收费；“价格”字段price，应包含跟价格相关的所有信息，包括服务1次、2次、包时、包夜、包天等多少钱；
3.“服务1次的价格”字段price1，优先从“价格”字段price中提取，"p"表示服务一次、"pp"表示服务两次；如果无法提取，再从服务反馈中提取；最后需要把非标准的表达统一转化成数字，如2k转化成2000、10张转化成1000等；
4.“友情提示”字段，是指是否要定金、是否上门、是否收现金，以及一些不提供服务的情况如“无套”“磕药”“酒后”“后花园”等
